# Resume_site
Адаптивный сайт-портфолио медиадизайнера: проекты, опыт работы, навыки и контакты. Поддержка русского и английского языков, управление контентом через CMS.

## Структура проекта

| Папка | Назначение |
| --- | --- |
| `frontend/` | Публичный сайт, компоненты, стили и переводы RU/EN |
| `backend/` | API и серверная логика проектов и медиа |
| `cms/` | Схемы, настройки и расширения будущей CMS |
| `shared/` | Общие контракты данных сайта, API и CMS |
| `tests/` | Модульные, интеграционные и браузерные проверки |
| `tests/fixtures/uploads/` | Синтетические файлы для проверки загрузки проектов |
| `deploy/` | Будущие конфигурации контейнеров, прокси и окружений |
| `scripts/` | Скрипты локального запуска и деплоя |
| `docs/` | Архитектура и сценарии проверки |
| `storage/uploads/` | Локальные загруженные файлы, исключённые из Git |
| `references/` | Личные исходные материалы, исключённые из Git |

Реализован первый визуальный прототип фронтенда с демонстрационными проектами.
CMS, серверная логика и инфраструктура ещё не реализованы. Файлы `.gitkeep` сохраняют
пустые каталоги в Git; их можно удалить при добавлении реальных файлов.

## Локальный просмотр

Требуется Node.js. Из корня репозитория выполните:

```sh
node scripts/dev/serve.mjs
```

Откройте http://127.0.0.1:5173. Установка зависимостей не требуется.
Остановка — Ctrl+C, изменения видны после обновления страницы.
Проверки: `node --test tests/unit/frontend/projects.test.mjs`.
Подробности: [frontend/README.md](frontend/README.md).
Визуальные решения по ТЗ: [docs/frontend-concept.md](docs/frontend-concept.md).

## Дальнейшие решения

1. Согласовать содержание, дизайн и структуру страниц.
2. Выбрать фронтенд и CMS, определить хранение медиа и целевой хостинг.
3. Уточнить необходимость отдельного бэкенда: API выбранной CMS может быть достаточно.
4. Реализовать вертикальный сценарий: создание проекта в CMS → загрузка обложки
   и галереи → публикация → отображение на сайте.
5. Добавить автоматические проверки и настроить деплой.

Описание границ компонентов: [docs/architecture/README.md](docs/architecture/README.md).
Сценарии загрузки и публикации: [docs/testing.md](docs/testing.md).
