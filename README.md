# Фронтенд

## Первый вариант

Запуск из корня репозитория (требуется Node.js):

```sh
node scripts/dev/serve.mjs
```

Открыть http://127.0.0.1:5173. Сервер отдаёт только каталог `frontend/`,
слушает локальный интерфейс и не публикует сайт в интернете.
После правок обновите страницу. Остановка — Ctrl+C в терминале сервера.
Можно также выполнить `npm run dev` из `frontend/`; установка пакетов не нужна.

Проверки: `node --test tests/unit/frontend/projects.test.mjs` из корня.

Текущая версия — модульный HTML/CSS/JavaScript без внешних зависимостей.
Она демонстрирует композицию и просмотр кейсов, а не работающую CMS.

## Как дорабатывать

- `src/data/projects.js` — демонстрационные данные и обложки, не реальные работы автора.
- `src/lib/project-repository.js` — точка подключения CMS: возвращает нормализованные проекты.
- `src/components/project-card.js` — карточка в асимметричной сетке.
- `src/components/project-detail.js` — просмотр отдельного проекта.
- `src/styles/tokens.css` — цвета и шрифты темы.
- `src/styles/main.css` — сетки, компоненты, адаптивность, эффекты наведения.
- `index.html` — основные разделы и редакционный контент.

Следующая работа добавляется записью в данные, без копирования HTML карточки.
Формат: slug, number, title, subtitle, category, year, image, alt, layout,
idea, approach, role. Галерея пока не реализована. При подключении CMS нужно
добавить валидацию её данных, загрузку опубликованного контента и реальные медиа.

Ссылки вида `#project/tishe` открывают проект напрямую; Escape, кнопка закрытия
и браузерная история поддерживаются. Системная настройка уменьшения движения
отключает переходы. Контакты и биография ждут реальных данных.

Связь с ТЗ: [../docs/frontend-concept.md](../docs/frontend-concept.md).

- `src/components/` — переиспользуемые элементы интерфейса.
- `src/pages/` — страницы сайта; расположение уточним под выбранный фреймворк.
- `src/styles/` — стили и параметры оформления.
- `src/lib/` — клиент API и вспомогательная логика.
- `src/locales/ru/`, `src/locales/en/` — переводы интерфейса.
- `public/images/`, `public/fonts/` — статические ресурсы сайта.

Портфолио и медиа, загруженные через CMS, должны поступать из API и хранилища.
В публичные ресурсы не помещаются пароли, приватные резюме или исходные референсы.
