# CMS

- `schemas/` — модели проекта, страницы, перевода и медиа.
- `config/` — настройки выбранной CMS без секретов.
- `extensions/` — дополнительные поля и поведение, если потребуются.

CMS ещё не выбрана. Для облачного сервиса здесь хранятся только необходимые
настройки и схемы; для самостоятельного размещения — исходники и конфигурация.
Доступ к редактированию и загрузке требует авторизации. Публичный сайт читает
опубликованные проекты; черновики доступны только разрешённому предпросмотру.
