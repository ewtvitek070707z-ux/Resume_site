# Бэкенд

- `src/modules/projects/` — серверная работа с проектами портфолио.
- `src/modules/media/` — проверка и обработка загрузок.
- `src/config/` — конфигурация приложения.
- `src/middleware/` — общая обработка запросов и доступа.

Отдельный сервер пока не обязателен. Если выбранная CMS обеспечивает API,
авторизацию и загрузку файлов, используем её возможности без дублирования.
В таком случае этот каталог можно убрать после архитектурного решения.
