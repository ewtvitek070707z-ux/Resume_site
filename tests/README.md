# Тесты

- `unit/frontend/`, `unit/backend/` — изолированные проверки логики.
- `integration/cms/` — проверка API CMS, сохранения проектов и медиа.
- `e2e/` — полный путь от редактирования в CMS до отображения на сайте.
- `fixtures/uploads/valid/` — допустимые синтетические файлы.
- `fixtures/uploads/invalid/` — файлы для проверки отказов и ограничений.

Автоматические тесты и тестовые файлы ещё не созданы. При выборе CMS добавим
инструменты и команды запуска. Тестовые загрузки используют отдельное окружение
и не должны создавать контент в рабочей CMS.

Сценарии: [../docs/testing.md](../docs/testing.md).
