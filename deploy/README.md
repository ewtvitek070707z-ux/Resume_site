# Деплой

- `docker/` — контейнеры и Compose, если потребуются на выбранном хостинге.
- `nginx/` — конфигурация обратного прокси, если размещение этого требует.
- `environments/` — шаблоны и описание окружений без секретов.

Хостинг пока не выбран; конфигураций рабочего развёртывания ещё нет.
Нужны отдельные тестовое и рабочее окружения CMS и медиа-хранилища.
Пароли и токены передаются через настройки хостинга или локальные `.env`.
Примеры переменных можно хранить в `.env.example` с фиктивными значениями.
При размещении CMS необходимо предусмотреть резервирование её данных и медиа.
